Chapter 07 · Infrastructure

A small system with no mandatory usage bill.

Talkivana combines free-tier text generation, public-repository compute, local open-source media engines, and quota-based YouTube APIs. Nothing here means unlimited: the design stays at ₹0 by keeping the daily workload bounded and stopping visibly when a free allowance is unavailable.

“Free” describes the current operating path, not a lifetime guarantee

Provider limits, model availability, GitHub policy, and YouTube quotas can change. The automation does not promise infinite free capacity and it never switches itself to paid usage.

Infrastructure circuit

Where the work actually runs

GitHub is the control plane and temporary computer. Gemini is used only for language content. Speech, graphics, thumbnails, and video assembly run as software on the GitHub runner rather than as metered media APIs.

01 · ORCHESTRATE

GitHub Actions

Starts scheduled jobs, exposes each stage, stores short-lived artifacts, and passes approved work between gates.

Cost basis · standard ubuntu-latest runner in a public repository
02 · THINK

Gemini 3.5 Flash-Lite

Creates the structured lesson pack, performs bilingual QA, and audits the final conversation for naturalness.

Cost basis · Gemini API free tier, bounded by project RPM/TPM/RPD
03 · SPEAK

Chatterbox V3

Runs the open-source multilingual model against the fixed English and German reference voices.

Cost basis · no per-character service call; runner compute is the constraint
04 · BUILD

Pillow + FFmpeg

Draws frames and thumbnails, aligns narration, and encodes the long videos and Shorts.

Cost basis · open-source packages using temporary runner CPU and disk
05 · DELIVER

YouTube APIs

Uploads privately, applies metadata and thumbnails, schedules only approved assets, and reads analytics.

Cost basis · quota-limited API access with no per-upload API fee

Gemini accounting

Requests, not prepaid credits

The Gemini key does not contain a fixed wallet of credits. Google evaluates the project against model-specific requests per minute, tokens per minute, and requests per day. The active allowance is visible in AI Studio and daily request limits reset at midnight Pacific Time.

NORMAL PATH

Three calls per pack

One daily pack normally needs three structured Gemini responses. The four lessons are generated together; it is not one paid call for every sentence, slide, or voice line.

FAIL-CLOSED PATH

Eight attempts maximum

max_generation_requests_per_run is set to eight. If Gemini is slow, returns invalid output, reaches a project limit, or remains unavailable after retries, the workflow fails before creating an approval issue.

Why the bill stays at zero

Every expensive-looking task has a non-metered path

The saving does not come from one unlimited provider. It comes from assigning each task to a bounded free service or an open-source engine and avoiding paid fallbacks.

Capacity math

Why normal usage does not immediately exhaust the allowances

A regular day creates one pack, makes about three Gemini requests, and later uploads four approved assets. The media-heavy work does not consume Gemini tokens, and the daily provider counters reset on their own schedules.

1 PACK / DAY

Generation is consolidated

Two Shorts and two long lessons are returned together, reducing model calls and keeping the review unit coherent.

0 TTS API CREDITS

Speech runs locally

Chatterbox consumes compute time, not commercial characters or voice credits.

DAILY RESET

Quotas replenish

Gemini request-per-day limits and YouTube daily quota reset rather than accumulating forever. Reset timing and active limits are provider-controlled.

PUBLIC REPO

Compute is not metered by minutes

The workflows use standard Linux runners in a public repository, not paid larger runners.

NO AUTO-UPGRADE

A failure cannot create a surprise bill

The workflow has no logic that enables billing, purchases quota, or silently selects a paid service.

VISIBLE STOP

Limits become workflow errors

A missing approval request usually means an upstream job failed or was skipped; it does not mean the system spent money to continue elsewhere.

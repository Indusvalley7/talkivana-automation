YouTube quotas

Two ceilings that look similar

Cloud project quota and channel anti-abuse throttles are different systems. More quota units do not remove a channel-level HTTP 429.

PROJECT QUOTA

Counted API calls

YouTube currently documents a default 100 daily videos.insert calls in a separate upload bucket and 10,000 daily units for other endpoints. A thumbnails.set call is approximately 50 units.

CHANNEL THROTTLE

Recent-upload protection

uploadRateLimitExceeded means the channel uploaded too many thumbnails recently. YouTube documents the error but does not publish an exact safe count or reset interval.

Observed Talkivana evidence—not an official limit

Ten custom-thumbnail uploads succeeded across roughly 17 hours; the next attempt failed with HTTP 429. That suggests a rolling channel throttle near the current workload, but it must not be presented as a guaranteed “10 per day” rule.

Thumbnail hardening

Planned safe operating policy

This policy is the recommended next change; it is documented here as planned until the workflow implementation is merged and verified.

Budget five successful applications per rolling 24 hours

Four normal daily assets plus one reserve. This is deliberately below the observed edge.

Do not hammer a 429

Convert the response to “thumbnail deferred,” preserve the uploaded video, and retry after the cooling window.

One backfill per day

Pause backfills whenever normal production needs the thumbnail budget.

Apply final thumbnails late

Prefer application after final approval so revisions do not spend channel throttle budget repeatedly.

Gemini free tier

Reusable, but never unlimited

Free-tier rate limits are project- and model-specific, commonly measured as requests per minute, tokens per minute, and requests per day. Daily quotas reset; model availability and limits may change.

SUSTAINABLE BEHAVIOR

Small structured calls

One bounded daily pack, cheap revisions before rendering, backlog cap, and explicit failure on exhaustion.

NOT GUARANTEED

Permanent capacity

A free API key does not pre-purchase years of service. The active allowance must be checked in AI Studio, and a later provider/model change may require code changes.

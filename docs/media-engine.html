REPRODUCIBILITY

Fixed settings

Seed 271828, controlled exaggeration and CFG weight, approved references, and no automatic fallback voices.

Speaker count rule

Two-person conversations use two distinct voices. A scene with more people requires additional approved reference voices; the system must not invent or silently substitute them.

Pacing & duration

Fit the silence—not the German

Speech is never sped up to force a five-minute target. If a long lesson exceeds 330 seconds, duration fitting removes only safe tutor-transition silence while preserving German audio and learner practice gaps.

Thumbnail engine

Deterministic, distinct, and zero-fee

A checked-in thumbnail-design profile drives Pillow layouts. Headlines, palettes, and composition vary by lesson while mobile contrast, safe zones, file size, and exact dimensions remain fixed.

Current operational caution

YouTube’s custom-thumbnail endpoint has a separate channel throttle. The generator is free, but applying too many thumbnails quickly can return HTTP 429. See Costs & limits for the observed evidence and planned hardening.

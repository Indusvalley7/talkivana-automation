Legal · Effective 23 October 2026

Privacy, in plain language.

Talkivana Automation is a privately operated production tool for the owner of the Talkivana YouTube channel. It is not offered as a public service to third parties.

Google access

What the application reads and changes

After the channel owner grants permission, the application may access YouTube channel, playlist, and video information; upload and manage channel videos; and read YouTube Analytics reports used to assess content and publishing times.

Purpose

How the data is used

Google user data is used only to operate the Talkivana workflow, publish owner-approved videos, organize them into playlists, maintain the schedule and tracker, and assess their performance. It is not sold, used for advertising, or shared with data brokers.

Storage

Where sensitive information lives

OAuth credentials are stored as encrypted GitHub Actions secrets and are not committed to the public repository. Workflow logs and generated artifacts follow GitHub Actions retention settings. Access credentials remain until the channel owner replaces or revokes them.

Public documentation contains no credentials

The field guide explains system behavior, but never exposes API keys, OAuth secrets, refresh tokens, private preview URLs, or voice recordings.

Control

Revoke access at any time

The channel owner can remove Google access from the Google Account connections page. Questions about this policy can be sent to syxora216@gmail.com.
